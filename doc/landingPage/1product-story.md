📄 Product Story
1. Pourquoi ce projet existe ?

Ce projet est né d'une situation réelle. Ma mère est atteinte de la maladie d'Alzheimer et notre famille a dû s'organiser avec différents outils (Excel, Google Drive, messages...). Les informations étaient dispersées, difficiles à retrouver et compliquées à partager. J'ai voulu créer l'outil que nous aurions aimé avoir : un espace unique pour mieux accompagner un proche dépendant.

2. Mission

Faciliter la coordination entre les familles, les aidants et, à terme, les professionnels de santé autour d'un proche dépendant.

3. Vision

Offrir un espace collaboratif où chacun dispose des bonnes informations au bon moment, afin d'accompagner un proche avec plus de sérénité.

4. Le problème

Aujourd'hui, les informations sont dispersées entre :

messages ;
appels ;
fichiers Excel ;
dossiers partagés ;
agendas.

Résultat :

perte d'informations ;
oublis ;
manque de coordination ;
charge mentale importante.
5. Notre solution

Le CareGroup est un espace partagé qui réunit la famille, les aidants, le patient (lorsque cela est possible) et, à terme, les professionnels de santé. Il centralise les informations importantes afin que chacun puisse agir avec les mêmes repères et au bon moment.

Un CareGroup qui centralise :

les rendez-vous ;
les documents ;
les tâches ;
les messages ;
les informations d'urgence ;
les dossiers médicaux.

Chaque membre accède uniquement aux informations qui le concernent selon son rôle.

6. Les utilisateurs
👨‍👩‍👧‍👦 Famille
❤️ Aidants
🧓 Patient (selon son autonomie)
👩‍⚕️ Professionnels (à terme)
7. Notre promesse

Permettre à chacun de savoir ce qui se passe autour d'un proche dépendant afin de mieux l'accompagner, ensemble.
