# Foundations

## 1. Vision
Créer une expérience numérique qui aide les familles à mieux accompagner un proche dépendant.

L'application ne doit pas être perçue comme un outil médical complexe, mais comme un espace simple permettant à plusieurs personnes de collaborer autour d'une même situation.

## 2. Design Principles

### ❤️ L'humain avant la technologie

Chaque décision doit commencer par une question :

"Est-ce que cela facilite réellement la vie des personnes qui accompagnent un proche ?"

La technologie est un moyen, jamais une finalité.

### 🤝 La coordination avant l'information

L'objectif n'est pas seulement de stocker des données.

L'objectif est de permettre aux personnes de travailler ensemble.

Une information utile est une information :

accessible ;
comprise ;
partagée avec les bonnes personnes.

### 🌿 La simplicité avant la complexité

Les utilisateurs arrivent souvent avec une charge mentale importante.

L'application doit réduire cette charge, jamais l'augmenter.

Nous privilégions :

moins d'étapes ;
moins de choix inutiles ;
des actions évidentes.

## 3. UX Principles

### Compréhension immédiate

Chaque écran doit répondre rapidement :

- Où suis-je ?
- Que puis-je faire ?
- Quelle est la prochaine action ?

### Une action principale

Chaque écran possède une action prioritaire clairement identifiable.

Exemple :

Page rendez-vous  ==> Action principale  ==> Ajouter un rendez-vous

Les autres actions restent secondaires.

### Montrer l'essentiel avant le détail

L'utilisateur doit voir d'abord :

ce qui est important aujourd'hui ;
ce qui demande une action ;
ce qui est urgent.

Les informations secondaires restent accessibles mais discrètes.

### Accompagner plutôt que demander

L'application doit guider.

Elle doit éviter :

"Erreur : champ obligatoire."

Et préférer :

"Ajoutez le nom de votre proche pour créer votre CareGroup."

## 4. Product Values

### Confiance

Les informations concernent des personnes réelles et des situations sensibles.

**L'interface doit inspirer :**

- sécurité ;
- sérieux ;
- respect;
- Bienveillance;

**Le vocabulaire doit rester humain.**

Privilégier :

✅ proche

✅ accompagner

✅ aider

**Éviter :**

❌ dossier patient froid

❌ gestionnaire médical

**Inclusion**

L'application doit être utilisable par des personnes avec des niveaux numériques différents.

Elle doit fonctionner pour :

un enfant adulte ;
un grand-parent ;
un aidant ;
un professionnel.
5. Accessibility Principles
Lisibilité
textes suffisamment grands ;
contraste élevé ;
espaces généreux.
Simplicité cognitive

**Éviter :**

trop d'informations simultanées ;
trop de couleurs ;
trop de notifications.
Actions faciles

**Les boutons importants doivent être :**

visibles ;
suffisamment grands ;
facilement accessibles.
6. Interface Rules
Couleurs

**Une couleur doit avoir une fonction.**

Exemple :

Bleu → confiance / action principale

Vert → validation / positif

Orange → attention douce

Rouge → urgence uniquement

**Icônes**

Une icône doit toujours accompagner un sens clair.

Elle ne remplace pas un texte important.

**Espacement**

L'espace est un outil de compréhension.

Une interface respirante est plus rassurante.

**Animations**

Les animations servent à :

expliquer ;
guider ;
confirmer une action.

Elles ne servent pas à décorer.
